WAX - Local music player
========================

Portable: copy this folder anywhere (a drive, a USB stick) and open Wax.exe.
Nothing gets installed. Everything is saved in the "data" folder created next to the exe.
To take your setup with you, copy the whole folder.

Requirements: Windows 10/11 (uses WebView2, which ships with Windows).

Getting started: Local Files -> Add folder.

Taskbar / start with Windows: keep this folder in a fixed place (e.g. C:\Apps\Wax),
  open Wax and right-click its taskbar icon -> Pin to taskbar.
  Settings -> Window: Start with Windows, Start minimized, Add to Start menu.
Recommended layout: Music > Artist > Album > tracks.

Settings: "Local" menu (top right) -> Settings.
  Crossfade, volume normalization, Auto DJ, equalizer, lyrics, images,
  system tray, global shortcuts, Last.fm / ListenBrainz, Discord.

Also: Folders view, library check (missing covers, lyrics, tags), duplicates,
  CUE sheets, playlist folders, ratings, sleep timer (moon button),
  copying playlists to a folder / USB stick.
  Full-screen Now Playing, Wrapped (Your Stats), New Releases (Browse),
  AutoEQ and crossfeed (Equalizer), output device and WASAPI exclusive mode
  (Settings -> Audio output), Spotify playlist import (Exportify CSV). Last.fm extras (popular songs,
  related artists, bios) need your free Last.fm API key (Settings).

Shortcuts inside Wax: Space = play/pause · Ctrl+Left/Right = previous/next
  Ctrl+Up/Down = volume · Ctrl+F = search · double-click = play · right-click = more options
Global shortcuts (default): Ctrl+Alt+P play/pause · Ctrl+Alt+Left/Right · Ctrl+Alt+Up/Down
  Ctrl+Alt+L favorite · Ctrl+Alt+W show Wax · Ctrl+Alt+M mini player
